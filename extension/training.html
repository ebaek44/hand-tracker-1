AFTER COLLECTING
  1. Export your dataset. Aim for 100+ samples and at least 3 separate recordings per pose.
  2. Run the local training command from the project folder:.venv/bin/python training/train.py --data /path/to/hands-on-dataset.json --install
  3. Review training/output/report.json, then reload the extension at chrome://extensions.

Python is only for training. Using the extension needs no Python or server. See training/README.md for setup and validation guidance.
